What this session is

Everything that was one agent's job in session 91c32933—searching, classifying, reading papers, auditing quality—now has a dedicated stage, a dedicated instruction document, and a dedicated blame boundary. The agent prompts written here became the files in docs/agent_prompts/ that every subsequent session references.
